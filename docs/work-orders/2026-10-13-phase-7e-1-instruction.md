# WO-RUNNINGAI-PHASE-7E-1 (지시문 원문)

> 사용자가 2026-10-13에 전달한 작업지시서. 아래는 원문 그대로이며 편집하지 않았다.

---

WO-RUNNINGAI-PHASE-7E-1

Historical Activity Importer & Analysis Version Fix

역할

RunningAI 시니어 백엔드 아키텍트 / 데이터 마이그레이션 리드 / QA.

목표

과거 운동 기록을 RunningAI에 안전하게 통합한다.

Phase 7E-0 조사 결과를 기준으로 기존 Garmin Backfill을 재개발하지 않는다.

이번 단계는 개발 코드 및 운영 DB 사본 검증까지 진행한다. 실제 운영 데이터 적재는 수행하지 않는다.

STEP 1 — 기존 산출물 확인

* main-3 Git 상태 확인
* 7E-0 결과보고서 검토
* 미커밋 코드 및 문서 보존
* 운영 V20 / 개발 V23 구분 유지
* 현재 ChatGPT OAuth 연결은 합성 데이터 유지

STEP 2 — Intervals 전용 활동 Importer 개발

Intervals.icu OAUTH_CLIENT 출처 활동 27건을 대상으로 한다.

요구사항:

1. 1Hz 활동 스트림 13종 수집
2. 활동 원본 Raw 저장
3. 기존 Activity 모델에 정규화
4. Garmin 및 Strava와 구별되는 출처 관리
5. 원본 Activity ID 보존
6. 활동 날짜·타임존·거리·시간 검증
7. 심박·케이던스·파워·보폭·접지시간·수직진폭 지원
8. 기존 활동과 중복 매칭
9. 재실행 멱등성
10. 실패 시 재시도 및 진행 상태 기록
11. 데이터 품질 및 결측 정보 표시
12. 중복 활동에 대한 원본 ID 연결 정보 보존

Garmin 외부 ID를 임의 생성해 저장하지 않는다.

기존 Garmin 활동과 동일 운동이 확인되면 신규 활동을 만들기보다 출처를 연결하고 더 풍부한 상세 정보를 보강한다.

활동 동일성은 ID, 시간, 운동 종류, 거리, 지속시간 등 복수 근거로 판단한다. 애매한 경우 자동 병합하지 않는다.

원본에 랩이 없다면 랩을 임의 생성하지 않는다.

STEP 3 — 러닝 분석 버전 관리 수정

Phase 7E-0에서 발견된 기존 분석 재사용 결함을 수정한다.

현재 RUNNING_ANALYSIS_V1 문자열만으로 V22 이전 분석과 이후 분석을 구별할 수 없다.

요구사항:

* 분석 로직 버전을 명시적으로 구별
* 데이터 변경·분석 버전 변경 시 재분석 판단
* 정상적으로 최신 분석된 활동은 재사용
* 구버전 7건이 자동 재분석 대상이 되도록 검증
* 기존 활동·샘플·랩 데이터 보존
* 전후 분석 결과 및 결정성 검증
* 재분석 실패 시 이전 결과 보존 및 복구

문자열만 변경하는 임시 수정이 아니라 향후 분석 엔진 변경에도 적용 가능한 정책을 설계한다.

STEP 4 — 실제 운영 DB 사본 검증

개발용 사본 환경에서 다음을 확인한다.

* Intervals 전용 27건 적재
* 성공·실패·중복·결측 현황
* 1Hz 스트림 수집 품질
* Garmin과의 중복 방지
* 동일 Import 재실행 시 신규 행 0건
* 중단 후 재개
* 러닝 분석 결과 생성
* 기존 Garmin 활동 재분석
* TrainingContextV2 반영
* MCP 읽기 도구 정상 조회

운영 DB에 접근하는 쓰기 경로는 사용하지 않는다.

STEP 5 — Strava 및 Apple Watch 과거 기록 준비

2026-07-02~08-26의 STRAVA 34건은 별도 복구 대상으로 유지한다.

사용자가 Strava 계정 전체 아카이브를 요청할 예정이므로 아카이브가 도착하기 전까지 원본 파일을 추측하지 않는다.

대신 다음을 구현하거나 문서화한다.

* FIT/TCX/GPX 파일 지원 현황 조사
* Strava activities.csv 매칭 설계
* Apple Health export.xml 지원 가능성 검토
* 기존 Intervals 활동 ID 및 Strava ID 매칭
* 27건과 34건 중복 가능성 분석
* 원본 데이터 충실도 평가

Strava 비공식 스크래핑이나 서비스 정책을 우회하는 수집을 하지 않는다.

Strava 아카이브가 도착하면 샘플 파일 구조를 먼저 검사한 뒤 Importer 범위를 확정한다.

STEP 6 — ChatGPT 기능 연계

현재 MCP 읽기 도구 7종이 신규 활동과 재분석 결과를 정상 조회하는지 개발 환경에서 검증한다.

ChatGPT의 기존 OAuth Worker·Gateway·합성 데이터 연결은 변경하지 않는다.

이번 단계에서는 MCP 쓰기 기능을 신규 공개하지 않는다.

기존 A+B-1 승인 기록은 보존하되, 이번 작업지시서만으로 운영 변경을 실행하지 않는다.
